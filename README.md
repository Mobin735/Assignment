# Photography studio

The photography website and Instagram-style page live in [`studio`](studio). They share one photo catalog.

```bash
cd studio
npm install
npm run dev
```

Edit [`studio/src/brand.js`](studio/src/brand.js) to set the real studio name, handle, bio, and contact email.

`Frontend` and `Backend` are an earlier unrelated project and are not used by this site.
